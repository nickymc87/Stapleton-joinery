# Stapleton Joinery — Measure & Quote (prototype)

Mobile-first prototype for browser hosting (e.g. GitHub Pages). The entry point is `index.html`.

## Deploy on GitHub Pages
1. Upload `index.html` to the root of a repository (not nested inside a folder).
2. In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, then Save.
3. Open the published URL once GitHub completes deployment.

## Important
- This is a demo, not a verified manufacturing/costing tool. All rates are examples.
- Photos and job data are saved only in local browser storage; they do **not** sync to other devices.
- Avoid storing real customer personal information on this prototype until data handling and storage are properly designed.
- GitHub Pages hosting makes the app source publicly accessible when publicly published; do not put confidential costs, credentials, or customer data in source files.
